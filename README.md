# Nexus Protocol

Showcase tactical FPS NEXUS PROTOCOL được xây dựng bằng HTML, native ES Modules và Web Components, với Clean Architecture bốn tầng.

## Development

```bash
npm install
npm run dev
```

Tailwind CSS được nạp qua CDN trong `index.html`. Dữ liệu mock nằm ở infrastructure và được truyền vào presentation qua `GetLandingDataUseCase`.
